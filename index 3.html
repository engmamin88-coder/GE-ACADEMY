⚛️ CT Physics & X-Ray Fundamentals
Build your foundation — from how X-rays are born to how a full CT image is created. Use the interactive demos to understand key concepts.
// Live Gantry Cross-Section

01 — What is CT?

CT (Computed Tomography) creates cross-sectional images by measuring how different tissues absorb X-rays from hundreds of angles. A computer reconstructs these measurements into 2D slices — stacked into a 3D volume.

💡 Core Principle

Attenuation = how much the tissue reduces the X-ray beam. Dense materials (bone, metal) attenuate more. Less dense (air, fat) attenuate less. The CT image is a map of attenuation values across the body slice.

02 — How X-Rays Are Produced

1

Cathode Heating

Electric current heats the tungsten filament → electrons released by thermionic emission (like boiling electrons off the metal surface).

2

Electron Acceleration

High voltage (80–140 kV) across tube accelerates electrons from cathode to anode. Higher kV = faster electrons = higher energy X-rays = deeper penetration.

3

X-Ray Production

Electrons strike tungsten anode → ~1% becomes X-rays, ~99% becomes heat. Two mechanisms: Bremsstrahlung (braking radiation) and Characteristic radiation. Anode rotates at 3,600–10,000 RPM to spread heat.

4

Beam Shaping

Collimators (tungsten blades) shape beam into fan/cone matching detector geometry. Pre-patient filters remove low-energy photons that add dose without improving image quality.

5

Detection & Reconstruction

Beam passes through patient → detector measures transmitted intensity at each element → DAS digitizes → reconstruction computer builds image from thousands of angle measurements.

03 — Hounsfield Units (HU)

All CT values are expressed in Hounsfield Units (HU). The scale is anchored: Water = 0 HU, Air = −1000 HU.

HU = 1000 × (μ_tissue − μ_water) / μ_water

This ensures CT values are reproducible across all scanners worldwide, regardless of manufacturer or technique used.

04 — Full Scan Sequence

1

Protocol Selection

Technologist selects kV, mA, rotation speed, pitch, FOV. Console sends parameters to all subsystems simultaneously.

2

Gantry Spin-Up

Motor accelerates gantry to target speed. "Tube ready" signal confirms anode at speed and filament at operating temperature.

3

HV On — Exposure

HVG applies kV across tube. Table moves patient at prescribed speed (pitch). Helical data acquisition begins and continues until anatomy is covered.

4

Data Acquisition

Detectors sample ~7,000 views/rotation. DAS digitizes and transmits via slip ring to reconstruction computer in real time.

5

Reconstruction

Algorithm (FBP / ASiR / AIR Recon DL / TrueFidelity) converts raw sinogram data to cross-sectional images. Displayed within seconds of scan completion.

6

Archive & Log

Images sent to PACS via DICOM. Dose report generated. System logs scan event and updates tube usage counters automatically.

🔧 Troubleshooting & Error Codes
Systematic fault diagnosis — from symptom to root cause to resolution. Diagnostic workflow, error categories, and action plans.

Diagnostic Workflow

1

Document the Symptom

Exact error code, when it occurs (startup/scan/idle), frequency, reproducibility. Check MDE alerts and remote service logs before arriving on site.

2

Isolate the Subsystem

Does it occur in all scan modes or specific protocols? Correlates with tube heat, room temperature, scan load? Use service mode tests to isolate.

3

Review Service Logs

Event log in service mode — look for pattern: recurring code, time-of-day correlation, count thresholds (arc count, error count).

4

Run Diagnostic Tests

Use ServIT for the specific error code. Run specified tests — don't skip steps. Confirm root cause before ordering parts.

5

Escalate if Needed

If inconclusive → open T3 Remote Support ticket with full log package. T3 can remotely access the system and confirm diagnosis.

Priority Classification

P1 — CRITICAL / SYSTEM DOWN

Emergency

System completely non-functional. Same-day or next-day delivery. Examples: Tube failure, HVG failure, main rotation motor. Contact GE Remote Support immediately.

P2 — URGENT / DEGRADED

Urgent

System running with reduced capability or artifacts. 1–3 day delivery. Examples: DAS board failure (ring artifact), single cooling loop issue, table errors.

P3 — ROUTINE / PM

Planned

Non-urgent parts for scheduled maintenance. 3–7 day delivery. Examples: Slip ring brushes, filters, belts, calibration phantoms.

Part Number Best Practices

💡 Pro Tips
  • Always use the system serial number (gantry nameplate) when searching — parts vary between generations
  • Check BOM (Bill of Materials) in ServIT for the exact configuration of that specific unit
  • Parts have supersession chains — current shipping part # may differ from legacy #. ServIT shows the active part
  • Tube assemblies require matching kV rating and focal spot to the generator — never substitute without verification
  • For detector modules, row position matters — order the specific row/channel, not a generic board

DOA Return Process

⚠ Critical — Never Skip

Failure to return defective parts within the required window (typically 10–30 days, region-dependent) results in a charge-back to the service contract.

  • Package defective part in same packaging as the new part received
  • Print and attach RMA label generated from iCenter
  • Ship via GEHC's designated carrier — not personal accounts
  • Log the RMA number in the Work Order before closing
